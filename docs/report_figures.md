# レポートの図の出典

レポート（説明資料）に載せる図が、どのファイルから作ったものかの記録。パスはリポジトリの直下からの相対パス。
`outputs/` は `.gitignore` で公開対象から外しているため、元のファイルはこのサーバーの中にだけある。

| 図 | 章 | 内容 | 元のファイル | 加工 | 状態 |
|---|---|---|---|---|---|
| 図1 | 1 概要 | 検品ラインの全体（アーム・ベルト・OK箱/NG箱・検査カメラ） | `outputs/step3_vla/eval_claude_act_seed1000/eval.mp4` の1秒時点（基準書「傷のみ」の1個目、2cm/s） | 1コマ切り出し、注釈（ロボットアーム、NGの箱、OKの箱、部品、ベルトコンベア、流れる向き）を追加。左上の字幕と右上の検査カメラの小窓は動画のまま | 作成済み：`docs/figures/fig1.png` |
| 図2 | 1 概要 | 部品5種類の見た目 | `outputs/step3_vla/eval_claude_act_seed1000/images/` の `scratch_only_04.png`（良品）、`scratch_only_06.png`（傷・小）、`scratch_only_01.png`（傷・大）、`scratch_only_00.png`（色ムラ・小）、`scratch_only_02.png`（色ムラ・大） | 5枚を300×300に縮小して横に並べ、部品名を付ける | 作成済み：`docs/figures/fig2.png` |
| 図4 | 5 結果（5.2） | 速度ごとの成功数の棒グラフ（スクリプト4cm/s仮定・ACT・スクリプト正確な速度） | 数値は `docs/step2.md` の50エピソードの結果 | 棒グラフを作成 | 保留（入れるか後で決める） |
| 図5 | 5 結果（5.3） | 学習にない基準書での比較の1コマ（左：VLA→NGの箱、右：Claude＋ACT→OKの箱） | `outputs/step3_vla/compare_vla_B.mp4`（切り出す時刻は未定） | 1コマ切り出し | 保留（入れるか後で決める） |

図1・図2は `uv run python scripts/make_report_figs.py` で作り直せる。

種類と画像の対応は、同じフォルダの `results.jsonl`（`variant` と `image`）で確認できる。

## 更新のルール

- 図を作ったら「状態」を「作成済み」にし、出力したファイルのパスを書き足す
- 切り出した時刻、選んだ画像を変えたら、この表も直す
